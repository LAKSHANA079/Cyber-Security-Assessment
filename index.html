Project Overview

Internship: YR NOVATECH – Task 2

Test Application: OWASP Juice Shop

Purpose: Identify potential security risks and understand defensive solutions.

Security Findings

SQL Injection Risk

Potential Risk: High

Displayed query construction appears to insert search criteria directly into SQL.

JWT Authentication

Status: Not Confirmed

A JWT-related training challenge message was observed. Further verification is required.

Security Recommendations

  • Use parameterized SQL queries.
  • Validate and safely handle user input.
  • Verify JWT signatures on the server.
  • Apply secure authorization checks.
